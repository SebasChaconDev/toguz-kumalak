ID: TRZ · Versión: 0.1 · Fecha: 2026-10-21 · Estado documental: EN_REVISIÓN · Owner: C.

## Lectura y alcance de evidencia

Esta matriz expande **las 246 decisiones**, con un único destino canónico por decisión. La aprobación del inventario valida la distribución de rutas, no prueba las capacidades. En lote 1 están redactadas 11.01 y 11.02: **17 decisiones con spec canónica EN_REVISIÓN**; las otras **229 tienen spec futura pendiente**. Los preliminares y ADR aportan contexto sin sustituir las specs aún no redactadas.

Cada fila enlaza el texto literal de [REG](decision-register.md) y una entrada de [IDX](index.md). Las fases PH-00–PH-07 son planes futuros del lote 5, no trabajo realizado. Los componentes son responsabilidades previstas, no directorios de código existentes. Las verificaciones VP son identificadores documentales propuestos, no tests implementados. Evidencia producto `PENDIENTE` significa que no existe evidencia ejecutada. La evidencia documental se distingue expresamente.
